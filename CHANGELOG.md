# Changelog

## [1.1.0] - 2026-09-10

Adds support for evaluating memory-augmented policies in ClevrSkills.

- Added memory-dependent task coverage and asset splits, including the
  `cs_mem` split.
- Added scratchpad generation tooling for producing task reasoning traces.
- Updated oracle, task, solver, and recording utilities needed by the memory
  task workflows.
- Added memory data-generation scripts and documentation updates for the
  ClevrSkills memory benchmark.

## [1.0.0] - 2024-07-14

First release.
